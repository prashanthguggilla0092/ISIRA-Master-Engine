# ISIRA Master Engine

## Multimodal Generative AI Assistant

ISIRA Master Engine is a multimodal AI assistant built with Python and Streamlit, powered by Google Cloud Vertex AI and Gemini.

### 🚀 Features

- 🤖 Generative AI powered by Gemini
- 🖼️ Image upload and multimodal interaction
- 🎤 Telugu voice input using Google Cloud Speech-to-Text
- 🔊 Telugu voice output using Google Cloud Text-to-Speech
- ☁️ Google Cloud Vertex AI integration
- 📊 Google Sheets API integration
- 🔐 Secure configuration using Streamlit Secrets
- 💬 Interactive Streamlit chat interface
- ⚡ Session state, caching and error handling
- 🌐 Custom HTML, CSS and JavaScript UI
- ✨ Three.js animated interface

### 🛠️ Tech Stack

- Python
- Streamlit
- Google Cloud Vertex AI
- Gemini 2.5 Flash
- Google Cloud Speech-to-Text
- Google Cloud Text-to-Speech
- Google Sheets API
- HTML / CSS / JavaScript
- Three.js
